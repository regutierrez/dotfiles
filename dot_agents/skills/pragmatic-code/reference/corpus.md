## Admitting a rule

A general rule needs a reachable failure, the owner that can prevent it, source support, installed-version constraints, existing tool coverage, valid exceptions, likely false positives, a simpler alternative, and caller-visible proof.

Local conventions and configured anti-slop rules are project policy, not universal language semantics. Keep deterministic diagnostics separate from judgment. One source project's architecture or framework does not establish behavior in another.
